Concept pages ↗

① The layers

pages/one file per route
composes a screen, owns page state
components/common · layout · cart · product
render, emit events. never see a URL
hooks/behaviour
loading · error · retry · derived values
services/HTTP only, no React
URLs, headers, status codes, DTO → model
lib/ · config/ · types/pure
formatters, constants, shapes
Forbidden: services importing a component, a component calling fetch, pages importing services/ directly. Dependencies point down only.

One screen change in a leaf re-renders that leaf, not the tree. Say it once, point at the DevTools highlight, move on.

③ Read chain — data falls down

pages/ProductsPage.jsx
calls useProducts(query)
hooks/useProducts.js
sets loading: true → spinner appears
services/productService.js
builds GET /products?q=…, passes the abort signal
services/http.js
logs the call · chaos checks · network
types/product.js
mapProduct(dto) — price_cents becomes price
hooks/useProducts.js
setData(models) · loading: false
pages/ProductsPage.jsx
re-renders → <ProductList products={data} />

④ Write chain — events climb, then fall back

components/ProductCard.jsx
click → onAdd(product) — knows nothing about carts
hooks/useCart.js
add(id) → optimistic state, then cartService.add
services/cartService.js
POST /cart → returns the whole cart
context/CartContext.jsx
value changes → only consumers re-render

Reads walk down the stack. Writes climb up as events, then come back down as state. If the screen is wrong, walk down. If the click does nothing, walk up.
